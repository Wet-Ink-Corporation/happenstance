Substrate — what this mock is composed from, and what it is not

Fifteen primitives, each verified by opening the file. Nothing was inferred from a filename, and nothing below is invented.

This workspace has no authored CSS, no token file and no component library. rg --files -g '*.css' -g '*.scss' -g '*.tokens.*' -g 'tailwind*' over the tracked tree returns nothing, and .redkiln/config.yaml omits design.capture for the same reason, in its own words: there is no app to screenshot.

But it does produce one stylesheet, and this mock uses it. target/doc/static.files/rustdoc-17e0aaed.css (69,637 bytes) is emitted by the gate's own documentation step, and it is what a markdown page rendered through rustdoc actually wears. 160 of its top-level rules are inlined below, declarations verbatim, selectors re-scoped to .rd, and not one layout override of our own; the extraction and its four stated omissions — fonts, media queries, renderer chrome, and the dark and ayu theme blocks — are documented in a comment at the top of this page's stylesheet. Read the caveat honestly: that stylesheet is the toolchain's, not this repository's, it is build output rather than tracked source, and it covers only one of HS-P0020's two open hosting options. mdBook's stylesheet does not exist in this worktree, so no frame claims to show it.

The design system these surfaces genuinely compose is textual: the constitution's document grammar and the gate's diagnostic grammar, both already enforced by xtask/src/lint_constitution.rs. Those are the primitives, and every one is listed here with the line it was read at.

What building this found

Five things the design could not have known before the specimens were drawn against a real renderer and measured. Each is a decision for the human at sign-off; none was made here.

  1. The 100-character problem-line budget is not reachable for this tree. _design.md's yield order says an over-long message moves its explanation into the rule atom and “cites it by path” — but the citation is what makes the line long. In the many-problems frame one line still breaches 100 characters — 112 — after that remedy is applied, because <PAGE_DIR>/guide/first-projection.md:7 plus see standards/pages/20-the-fold-line.md spends the budget before any prose. And the inherited spelling at lint_constitution.rs:369-378, transposed to this tree, is 111 characters on its own. Either the budget rises to about 120, or the citation shortens to a bare band number (see 20), or the yield order admits that some lines wrap.
  2. rustdoc wraps every page in a <details>, and PERMITTED_FOLD_MECHANISMS is empty. Verified in target/doc/happenstance/index.html: the whole docblock sits inside <details class="toggle top-doc" open>, and rustdoc ships a #toggle-all-docs control that closes it. Under rustdoc hosting the page is therefore already behind a disclosure mechanism nobody has observed, which is exactly what DT-8 Part 3 forbids — including for the declaration line itself, never-fold class 1. Part 3 needs a sentence saying whether a renderer-supplied, open-by-default wrapper is a “mechanism” at all. If it is, rustdoc hosting is blocked until it is observed; if it is not, the rule must say why the author's <details> differs from the renderer's.
  3. The verdict table's row count is stated twice, differently. Composition says three rows naming fail — need not answered; the States block declares four states including verdict-fail-unstated and indeterminate. Four rows are drawn, because the States block is what the mock is addressed from.
  4. The S4 selector regex is narrower than the messages its own precedent produces. _design.md declares problem lines match /^  \S+:\d+ — /, but check_shape addresses a whole file with no line number for four of its six problems, and _design.md's own S4 sketch shows one such line. Either the selector admits the line-less form, or the checker is obliged to synthesise a line number it does not have.
  5. The two S3 ceilings are not redundant, and the mock proves it. The seven-rule specimen measures well under 16,384 bytes. A rule-count ceiling and a byte ceiling catch genuinely different atoms, so neither can be dropped as implied by the other — which is worth stating, because “six rules is already a byte cap” is the obvious simplification someone will propose.

What the mock did not find. No surface needed a control the substrate cannot supply. Every frame is markdown a CommonMark renderer already renders, or text a terminal already prints. Nothing here requires a component, a token, a script or an asset that does not exist — which is the outcome this stage exists to confirm before any feature code is written.
