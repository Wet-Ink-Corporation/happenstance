# Report — One resolver for specification clause ids, next to the parser that owns them

## Findings Ledger

Six ACs, all satisfied by reachable behaviour with a `file:line` citation and a test behind
each — except AC-006, whose instrument is the gate itself and whose spec says so in advance.
Nothing stubbed, nothing skipped, nothing deferred out of this story's set. One deviation is
recorded as a finding rather than buried in a note.
