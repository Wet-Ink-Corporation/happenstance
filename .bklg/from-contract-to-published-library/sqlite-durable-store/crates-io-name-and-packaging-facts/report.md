## The one that is blocked, and why it is a handoff rather than a stub

`cargo publish` against the generated placeholder is the only irreversible act in
this project. A version can be yanked and never removed, and the criterion itself
frames the upload as *human-authorised*. A crates.io token is present on this
machine, so the story could have run the command — and that is precisely the
reason to name the decision rather than take it. The outcome this story treats as
a defect is a ledger row asserting a name is held; the outcome it treats as a
delay is this one.

Everything the upload depends on is done and checked, in the order the criteria
require:

1. The placeholder is generated by the repository's own command, with both
   licences copied in and a README and `lib.rs` that say plainly it has no
   functionality.
2. Its version claim was reconciled **first** — `0.2.0-alpha.1`, BR-05's — so
   `EC-004`, the unrecoverable one, is unreachable for this reservation.
3. The dry run packages, verifies and compiles.

What remains is one command, named in `_ledger.md` under *Reservation record*,
plus three facts to fill in afterwards: version, date, resolvable URL.

## What was deliberately not done

- **`publish = false` stays.** With `PUBLISHABLE` (`xtask/src/package.rs:86`)
  still naming three crates, deleting it would fail `reconcile()` on a
  promoted-but-unreconciled crate — the failure that module was written to
  produce. The line now carries a comment saying so, which makes `EC-005`
  unreachable by explanation rather than by hope.
- **`xtask/src/package.rs` and `RUNBOOK.md` are byte-identical.**
  `RUNBOOK.md:4230`'s stale *"`publish = false` removed"* checkbox is **recorded
  as superseded** in `_ledger.md` rather than edited: the runbook is the plan of
  record and its exit criteria are read at closeout by its owner.
- **No `include_str!` was added to `crates/happenstance-sqlite/src/lib.rs`.** That
  file belongs to the predecessor story; `rust,ignore` is the deliberate
  alternative and the sibling READMEs already set it.
- **`[package.metadata.docs.rs]`** — inert for an unpublished crate.
- **The placeholder's `rust-version = "1.85"`** — noted, not fixed. It binds
  nothing and the MSRV promise is BR-08's.
