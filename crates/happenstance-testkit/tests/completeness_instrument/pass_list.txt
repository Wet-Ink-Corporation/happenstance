# CF-27's recorded pass list (#144).
#
# Every rule of the event-store, concurrency and model families, run against
# `PrunedMemoryFixture`: a memory store behind a `WithholdingStore` that
# withholds the six events seeded before each rule begins. A rule that `ran`
# is a rule that cannot tell a pruned store from a young one, which is the
# outcome CF-27 specifies. A rule that `skipped` names the capability the
# fixture declines; the reason lives in the fixture's code, not here.
#
# Why whole-history pruning and not a scattered survivor set: every rule
# assumes it starts on a fresh store, and many read `Query::all()`, so a
# survivor from before the rule would fail them for a reason that has nothing
# to do with pruning. Holes inside a rule's own history need the rule's
# cooperation: ES-38's and ES-40's rules (#151, #154) supply it.
#
# Asserted by exact equality in
# `instrument_report_is_accurate_and_the_suite_cannot_tell`. A rule added to
# any family fails that test until its line is added here, in the same change,
# and the failure message prints the replacement. Regenerate with
# `--all-features`, or the model family's lines are missing from it.
#
# Format: `<family> ran <rule>` or `<family> skipped <rule> <CAPABILITY>`, where
# a rule gated on several capabilities names them all, comma-separated.
